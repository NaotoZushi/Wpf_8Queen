# Wpf_8Queen

WPFで8クイーン問題を解くサンプルアプリケーションです。

## 機能

- 8×8のチェス盤に8個のクイーンを配置して解を表示
- 「解く」で最初の解を表示
- 「次の解」で92通りの解を順番に表示
- 「リセット」で盤面を初期状態に戻す

## 開発環境

- .NET 8
- WPF
- Windows

## テスト

解法エンジンについて、以下を自動テストしています。

- 解が92通り存在すること
- 各解で同じ列・斜めにクイーンが存在しないこと
- 解が重複していないこと

GitHub ActionsでWindows環境のビルドとテストを自動実行します。
